
# 개발 상태와 다음 단계 — 2026-10-01 제출 기준

## 코드가 구현되어 있고 통합 검증을 계속하는 기능

- Raspberry Pi AI 음성 대화와 Jabra 녹음/출력
- 대화에서 필요한 내용을 기억하고 다시 활용하는 Persistent Memory
- 보호자 대시보드와 복약 일정 관리
- 복약 안내·음성 응답 확인, 장시간 미활동 안부 확인
- 터치 Display와 간단한 화면 게임
- Firebase 연결, 별도 격리 환경의 Auth 및 Rules 기준 예제

코드와 오프라인 테스트가 있다는 사실은 실물·운영 환경 검증 완료를 뜻하지 않습니다. 최신 제출 검사 범위는 README_SUBMISSION.md를 참고하세요.

## 아직 완성되지 않은 제품 기능

- 추억사진 보기와 사진을 활용한 대화
- 60GHz TI IWR6843AOPEVM 레이더 연동 및 레이더를 활용한 인지게임
- 실제 라디오 방송 청취·채널 조작의 최종 동작
- Pi 화면과 보호자 대시보드 UI/UX 개편
- 디자인팀 외형과 기구·센서·음성·화면의 최종 통합

초기 ESP32/24GHz 코드는 참고용으로 남겼습니다. 현재 60GHz 보드 연동의 완료 증거가 아닙니다. 기존 메모리게임/라디오 프리셋 코드 역시 위 제품 기능 전체의 완성을 뜻하지 않습니다.
